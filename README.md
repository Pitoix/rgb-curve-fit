# RGB Curve Fit

本地 Python 图形工具：在由 `R=x、G=y、B=1-x*y` 生成的 RGB 渐变图上选取路径点，使用 PCHIP 或多项式拟合 `y(x)`，并导出曲线及对应的 RGB 函数表达式。

## 运行

需要 Python 3.10 或以上，以及可显示桌面窗口的 Matplotlib 后端。

```bash
python -m pip install -r requirements.txt
python gui_rgb_fit.py
```

Windows 上使用实际安装的 `python` 即可，无需 `py` 启动器。程序需要在本地桌面运行，GitHub 网页不会直接运行 Python GUI。Linux 可能需要另行安装系统的 Tk 支持或选择已安装的 Qt 后端。

## 操作

- 左键添加点；同一 x（容差 1e-8）再次点击会更新旧点。
- 右键删除屏幕上最近的点。
- Clear：清空。
- Save PNG：保存整个界面。
- Fit: Spline / Fit: Poly：切换保形 PCHIP 样条与最高五次多项式；按钮显示当前模式。
- Export TXT：导出当前拟合曲线及 RGB 表达式，包含点坐标。
- 使用工具栏缩放、平移时暂停选点。

文件输出到脚本旁的 `output/` 文件夹。中文标题优先使用已安装的微软雅黑等字体，没有合适字体时自动使用英文。无需下载字体。

## 坐标及表达式

x 从左到右为 0–1；y 从下到上由 0 增至 1。点击坐标直接作为拟合曲线 `y(x)` 的取点。

内置渐变定义为 R=x、G=y、B=1-x*y，因此顶部 G=1、底部 G=0。G 是由一元曲线 `y(x)` 得到的颜色通道；预览和导出的颜色使用同一条曲线，不会对选点颜色进行第二次独立拟合。

PCHIP 样条准确经过取点并保持局部形状，不使用普通三次样条的振荡式外推。拟合在整个 x∈[0,1] 上绘制；选点区间之外保持最近端点的 y 值。样条仍导出为解析的分段三次多项式；TXT 按摘要、RGB 公式、归一化分段系数表和取点/RGB 表组织。每段使用 `t=(x-x0)/(x1-x0)`，避免显示数值很大的局部系数。拟合曲线经过取点时，取点表只显示一个 `y`，并有 `G=y`；多项式近似拟合不能经过取点时，分别显示 `y_point` 和 `y_curve`，RGB 对应 `y_curve`。数字采用能还原原浮点值的最短表示。`**` 表示乘方，`clip(v,0,1)` 表示 min(1,max(0,v))。这些是数学表达式文本，不能把整份文件直接当 Python 脚本运行。

这是程序生成的渐变图，不是任意图片取色器，也不是完整 RGB 色域。颜色按渐变公式计算，避免像素取整误差。
